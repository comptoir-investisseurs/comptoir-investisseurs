# Documents sources

Déposez ici les documents qui attestent une donnée : planches de fournitures,
communications techniques, fiches de lubrifiants, catalogues d'époque.

Rien de ce dossier n'est publié. Comme `guides-pdf/`, il est **hors de
`public/`** : aucun fichier n'y est servi statiquement. Il ne sert qu'à la
saisie — on lit le document, on saisit la valeur, on cite la source.

## Comment déposer

Sur GitHub, dans ce dossier, **Add file → Upload files**. Ou par ligne de
commande, comme pour les guides.

## Comment nommer

Le nom doit dire de quoi il s'agit : c'est ce qui sera recopié dans le champ
« source » de chaque valeur, et ce qui permettra à quelqu'un d'autre de
retrouver le document dans cinq ans.

```
omega-planche-fournitures-30mm-1957.pdf
omega-265-planche-eclatee.jpg
eta-2824-2-communication-technique.pdf
moebius-fiche-technique-9010.pdf
valjoux-7733-catalogue-fournitures.pdf
```

Formats acceptés : PDF, JPG, PNG. Une photographie de page nette et cadrée
droit vaut un scan — l'important est que les chiffres soient lisibles.

## Ce qui est le plus utile, par ordre

1. **Planches de fournitures Omega 30 mm** — elles donnent les références de
   commande, la seule donnée aujourd'hui totalement absente du site.
2. **Fiches techniques des lubrifiants** — Moebius publie viscosité à 0, 20 et
   40 °C, densité, plage de température.
3. **Communications techniques ETA** — pour les calibres modernes : cotes,
   rubis, fréquence, réserve de marche, couples de serrage.
4. **Catalogues de fournitures d'époque** — Cousins, Otto Frei, ou les
   catalogues suisses des années 1950-60.

## Ce qu'il ne faut pas déposer

Des documents dont vous ne détenez pas les droits et qui seraient
redistribués. Ce dossier n'est pas publié, mais il est versionné dans le
dépôt : ce qui y entre y reste. Une planche technique consultée pour saisir
des valeurs ne pose pas de difficulté ; un manuel complet sous droits, si.
